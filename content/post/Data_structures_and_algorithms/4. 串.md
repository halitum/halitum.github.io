# 串

## 1. 定义

一种操作受限的线性表，限定元素内容只能为字符，串由0个或多个字符组成（字符数为0的串为空串）

- 由一个或多个空格组成的串为空白串
- 串中任意多个连续字符序列为该串的子串
- 当两个串长度、各个位置对应字符都相等，称两个串相等

串的存储方式有 顺序存储、链式存储，实现方式和线性表一致



## 2. 模式匹配

模式匹配就是在 **目标串 s **中 寻找与 **模式串 t** 相同的子串



- **BF（Brute-Force）暴力算法**      时间复杂度O(m*n)

特点：i，j 每次都需要回退

```c
int BF(SqString s, SqString t){
    int i, j;
    while (i<s.length && j<t.length){    // 当两个串都遍历完则停止
        if (s.data[i] == t.data[i]){
            i++; j++;
        } else {
            i = i-j+1 ; j=0;             // 遍历回退，i++开始下一趟
        }
    }
    if (j>=t.length)                     // 检查是否匹配到模式串
        return(i-t.length);
    else
        return(-1);
}
```



- **KMP 算法**      时间复杂度O(m+n)

目的：避免 i 每次都需要回退，只需一次遍历即可找出字串

实现方式：通过“最大相同前后缀”计算模式串的 `NEXT` 数组，用来在模式匹配时得到 j 的正确回退值，避免重复比较

```c
// KMP 实现——伪代码
i=0; j=0;
while (s 和 t 都没扫描完) {
    if(j=-1 或者 他们所指的字符相同){
        i++; j++;
    } else {
        i 不变，j 回退到 j = next[j]（模式串右滑）;
    }
}
if(j 超界){
    返回(i-t.length);  // 模式匹配成功
} else {
    返回 -1;  // 匹配失败
}
```

```c
// KMP 实现
int KMPIndex(SqString s, SqString t) {
    int next[MaxSize], i = 0, j = 0;
    GetNext(t, next); // 求 next 数组
    while (i < s.length && j < t.length) {
        if (j == -1 || s.data[i] == t.data[j]) { // 如果匹配或者 j == -1
            i++;
            j++; // i, j 各增 1
        } else {
            j = next[j]; // i 不变，j 后退
        }
    }
    if (j >= t.length)
        return (i - t.length); // 匹配成功，返回模式串的首字符位置
    else
        return -1; // 匹配失败
}
```

每个串自身都有一系列长度不等的前后缀

`NEXT`数组的本质时寻找模式串中每个字符 之前的最大子串 的 所有前缀 中的“最长的相同前后缀长度”

递推法求`NEXT`数组

```c
int GetNext(SqString t, int next[]) {
    int j = 0;  // j 扫描模式串 t
    int k = -1; // k 记录 t[j] 之前与 t 开头相同的字符个数

    next[0] = -1;
	
    // 基于 next[j]，求 next[j+1]
    while (j < t.length - 1) { 
        while (k != -1 && t.data[j] != t.data[k]) {
            k = next[k]; // 右滑直至 tj = tk 或 k = -1
        }
        j++;
        k++;
        next[j] = k; // next[j+1] = k + 1
    }
}
```

求`nextval`数组 c 语言实现：

```c
int GetNextval(SqString t, int nextval[]) {
    int j = 0, k = -1;
    nextval[0] = -1;

    while (j < t.length - 1) { // 基于 next[j]，求 next[j+1]
        while (k != -1 && t.data[j] != t.data[k]) { // 若 tj ≠ tk
            k = nextval[k]; // 右滑直至 tj = tk 或 k = -1
        }
        j++;
        k++;
        if (t.data[j] == t.data[k]) { // 但若 tj+1 = tk+1
            nextval[j] = nextval[k]; // 直接滑至 nextval[k+1]
        } else { // 若 tj+1 ≠ tk+1
            nextval[j] = k; // nextval[j+1] = k + 1
        }
    }
}
```
